<h1>How to use the application</h1>

Download the app and run the main.py file.

Click **"See Meds"** to open the list of your medications.

Inside the **"See Meds"** section, click "Add" to register a new medicine to the list. You can click the left arrow (<) to go back to the main screen.

The **"Add"** form has different fields to fill in: name, dose, the first day you took the medicine, etc. Check it out! You can also cancel the operation. Once you save the medicine, the form cleans itself up and the widget will hide.

---

<h2>What can you do with it?</h2>
You can fill the form to add medicine, and it will be added to a SQLite database. The medicine in the database will be displayed in a table.
